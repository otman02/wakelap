#wakelap
une application web pour centraliser et gere les idées d'activites bde révile pédagogique (de courtes activités de 10 a 20 min au début de chaque aprés -midi de formation )

#fonctionnalites 
.enregestrer son nom complet 
. consulter les activites sous forme de cartes 
.le crude
.rechercher par le titre et filtrer par théme
.validation des formulaires avec messages d'erreur 
.responsive

#Technologies 
html ,tailwind css ,javascript
Axios
API REST


#instaltion

git clone https://github.com/otman02/wakelab.git cd wakelab

lancer l'API sur http://localhost:3000
ouvrir index.html dans le navigateur
